# 模考產生器（規劃中，尚未動工）

跨課綜合複習考卷產生器。跟 `new-lesson` skill（單課故事＋文法）是不同的功能線，**刻意分開**，不共用資料夾、不共用產出邏輯，理由見下方「跟 new-lesson 的分離原則」。

本檔只記「要做什麼、分幾階段」，不是實作細節文件——實作時再視需要另外補技術筆記。

## 跟 new-lesson 的分離原則

- **前端邏輯／樣式獨立**：新建 `assets/mock-exam.js`（＋需要的話 `assets/mock-exam.css`），不塞進 `assets/lesson-engine.js` / `assets/lesson.css`。模考的題型、計分邏輯跟課程引擎的故事／單字卡／SRS 是不同的互動模型，硬共用只會讓兩邊互相遷就、都變難改。
- **頁面放哪是另一件事**：`lessons/mock-exam.html` 還是會放在 `lessons/` 目錄，跟 `日文單字總表.html` 這類「跨課工具頁」放一起——這只是檔案位置沿用現有慣例，跟上面「邏輯不共用」不衝突。命名照 CLAUDE.md 現行規定用英數小寫連字號（不跟進舊工具頁的中文檔名）。
- **資料唯讀、不改 `data/vocab.json` schema**：v1、v2 只讀取現有欄位，不新增欄位、不影響 `validate-lessons.py` 或 `new-lesson` skill 的假設。
- **未來如果要額外資料（近義詞／誤用例句庫）**：開新檔 `data/mock-exam-extra.json`，不要塞進 `vocab.json`——保持 vocab.json 給引擎課單字卡用途的單純性。
- **未來如果需要 Claude 協助建題庫（例如批次生成近義詞／誤用例句）**：另開 `.claude/skills/mock-exam-bank/`，不動 `.claude/skills/new-lesson/`。目前判斷用不到，等做到 Phase 3 才確定。

> 2026-09-26：「單課小考」（學完一課的 10 題綜合題）已先做成 `assets/mock-exam.js`，題型含漢字読み、表記、文脈規定、克漏字、排序、讀解。
> 下面的跨課模考 Phase 1 可以直接重用它的組題邏輯（把出題範圍從一課換成多課）。

## Phase 1（目前要做的）

- 題型：**漢字読み、表記、文脈規定** 三種（言い換え類義、用法先不做，理由見下）
- 資料來源：唯讀 `data/vocab.json`
- 出題範圍：
  - 選第幾課（用 `vocab.json` 的 `lessons` 欄位篩選）
  - 全部單字隨機
  - （「常錯的題目」**不在 Phase 1**，因為需要作答歷史，見 Phase 2）
- 題數：5 / 10 / 15 / 20 可選，預設 10，不開放自由輸入
- 作答：當次生成、當次作答、顯示分數與對照解答；**重新整理就沒了，不記錄歷史**
- 產出物：`lessons/mock-exam.html` + `assets/mock-exam.js`（＋視需要 `assets/mock-exam.css`）

**為什麼先砍成三種**：漢字読み／表記／文脈規定的干擾項可以從「同詞性的其他單字」隨機抽，邏輯清楚、品質有把握。言い換え類義／用法需要語意判斷「這句話對不對」，光靠現有欄位隨機抽容易出現似是而非、其實也算對的干擾項，品質沒把握——放到 Phase 3 補資料再做。

## Phase 2（常錯題目 + 考卷紀錄）

- 新增出題範圍「常錯的題目」：需要作答歷史才能判斷「常錯」
- 新增獨立 localStorage 命名空間 `mock:` 前綴，只記模考本身的答對/答錯次數——**不接現有 SRS**（SRS 是「這個字在這課練得如何」，模考是「這個字考試常錯嗎」，語意不同、命名空間也不同，混在一起以後難維護）
- 每次考卷存一筆歷史紀錄（時間、範圍、題數、分數、錯題清單），本機 localStorage，數量上限待實作時再定（避免無限長）
- 限制：純靜態網站沒有後端，紀錄只在單一瀏覽器/裝置，換裝置看不到歷史——跟現有引擎的 SRS 進度是同樣的限制，不特別處理跨裝置同步

## Phase 3（言い換え類義／用法）

- 需要人工補一個「近義詞」或「誤用例句」小資料庫，存在獨立檔案 `data/mock-exam-extra.json`（不進 `vocab.json`）
- 這是額外的人工整理成本，不是純自動能生出來的——先看 Phase 1/2 用起來夠不夠，再決定要不要做

## Phase 4（遠期，非承諾）

- 文法選擇題（跨課、吃 `docs/n4-grammar.md`）：現有 `grammarQuiz` 是綁在單一課 JSON 裡的，模考要跨課，得另外設計資料存放方式（例如獨立的 `data/grammar-bank.json`），不能直接複用 `grammarQuiz` 的結構
- 目前只是先記著這個方向，還沒有設計
